# Auditoria de nicho — assistência para advocacia e consultórios (Curitiba)

Data: 2026-08-06 · Status: **decisão tomada — seções no hub empresarial, sem páginas próprias**

## Escopo da auditoria

Avaliar se compensa criar rotas dedicadas (`/assistencia-tecnica-advocacia-curitiba`,
`/assistencia-tecnica-consultorios-curitiba`) ou apenas aprofundar seções dentro do hub
já existente `/assistencia-tecnica-empresas-curitiba`.

## Sinais considerados

| Critério | Leitura |
| --- | --- |
| Intenção de busca | Termos por segmento ("suporte de TI para escritório de advocacia", "manutenção de computador consultório") têm volume local baixo e são satisfeitos por páginas de suporte empresarial genéricas. |
| Concorrência | Quem ranqueia em Curitiba são páginas de TI empresarial amplas, não landing pages por segmento. |
| Diferença operacional | O serviço executado é o mesmo do hub empresarial (manutenção, rede, backup, formatação). Não há oferta, preço ou SLA distinto comprovado por segmento. |
| Risco de canibalização | Duas páginas quase idênticas competiriam com o hub, diluindo autoridade sem conteúdo realmente novo. |
| Conteúdo verificável | Não há casos, contratos ou provas por segmento que possam ser publicados sem violar o gate de claims comerciais. |

## Decisão

**Não criar páginas próprias agora.** Tratar advocacia e consultórios como seções de contexto
dentro do hub empresarial, com linguagem específica (sigilo de dados de clientes/pacientes,
continuidade de agenda e prontuário, backup e rede estável), sem prometer conformidade legal,
certificação ou SLA que não esteja documentado.

## Gatilhos para reavaliar

Criar rota dedicada apenas quando pelo menos dois itens forem verdadeiros:

1. Demanda recorrente registrada na triagem para o segmento (≥ 10 leads qualificados/mês).
2. Oferta operacional distinta e documentada (escopo, prazo, valores) para o segmento.
3. Prova publicável (contrato, depoimento autorizado, caso real) sem violar sigilo.

Enquanto isso, o gate de claims comerciais continua bloqueando qualquer afirmação de
conformidade (LGPD, CFM, OAB) que não tenha fonte única no repositório.
